## [misa77: New Codec Decodes 2x Faster Than LZ4](https://github.com/welcome-to-the-sunny-side/misa77) ⭐️ 8.0/10

A new open-source compression codec called misa77 achieves up to 2x faster decompression than LZ4 on the Silesia corpus, with comparable or better compression ratios, at the cost of slower compression. This breakthrough in decompression speed can significantly improve performance in applications where decompression is a bottleneck, such as database queries, game asset loading, and network data transmission. misa77 achieves its speed by reducing branches and optimizing for out-of-order CPU cores, using a smart format that enables more memcpy operations. However, the codec is still experimental (v0.x.y) and provides no safety guarantees for invalid input.

hackernews · nonadhocproblem · Jul 15, 15:58 · [Discussion](https://news.ycombinator.com/item?id=48922838)

**Background**: LZ4 is a widely used lossless compression algorithm known for its extremely fast compression and decompression speeds. The Silesia corpus is a standard benchmark for lossless compression algorithms. Out-of-order execution is a CPU feature that allows instructions to be reordered for better performance, and misa77's format is designed to exploit this.
