Researchers discovered that Microsoft's Secure Boot implementation has been vulnerable to bypass since 2013 due to unrevoked bootloader shims, allowing attackers to load unsigned bootkits like BlackLotus. This undermines the foundational security guarantee of Secure Boot on millions of Windows devices, exposing them to persistent boot-level malware that can evade detection and survive OS reinstallation. The vulnerability, tracked as CVE-2023-24932, involves old bootloader shims that Microsoft failed to revoke, making Secure Boot bypass trivial. Microsoft has issued patches but they require manual steps and may break some systems.

**Background**: Secure Boot is a UEFI feature that verifies the digital signature of bootloaders to prevent unauthorized code from running during system startup. It relies on certificate-based trust chains. The vulnerability stems from Microsoft's failure to revoke old, trusted bootloaders that can be used to load malicious code.
