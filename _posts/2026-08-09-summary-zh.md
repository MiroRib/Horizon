## [W3C 1998 年文章“酷 URI 不会改变”至今仍引发共鸣](https://www.w3.org/Provider/Style/URI) ⭐️ 7.0/10

W3C 于 1998 年发布的文章“酷 URI 不会改变”在社区讨论中再次引发关注，凸显了其对现代网络实践的持久相关性。讨论强调了链接腐烂问题的持续存在以及稳定 URI 的重要性。 这篇经典文章至今仍是网络工程师和 SEO 专业人士的基石，因为链接腐烂持续影响互联网的信息完整性。其原则指导着 URI 设计的最佳实践，影响着当今网站的构建和维护方式。 该文章提倡使用永久不变的 URI 以防止链接腐烂，即超链接随时间失效的问题。社区评论提供了现实世界的例子，例如 1998 年 NSF 页面上的 404 错误，说明了该问题的持续性。

hackernews · Klaster_1 · Aug 9, 14:32 · [社区讨论](https://news.ycombinator.com/item?id=49231809)

**背景**: URI（统一资源标识符）是标识网络上资源的字符串，而 URL 是一种提供资源位置的 URI 类型。链接腐烂是指超链接指向已移动或删除的内容，导致链接失效的现象。这篇 W3C 文章由蒂姆·伯纳斯-李撰写，强调酷 URI 是那些保持稳定、不改变的 URI，以确保长期的可访问性。

## [通过势场证明所有阶幻六边形存在](https://gukov.dev/math/2026/08/02/new-magic-hexagons.html) ⭐️ 7.0/10

文章提出了一种新颖的证明，利用交互式势场方法证明了所有阶数 n 的幻六边形都存在。这扩展了已知结果，即在标准连续约束下，只有 1 阶和 3 阶幻六边形存在。 这一结果挑战了娱乐数学中长期存在的假设，并为算法设计和组合探索开辟了新途径。交互式势场方法提供了一种优雅且易于理解的方式来构造幻六边形，可能激发其他数学谜题的类似方法。 证明依赖于定义在六边形网格上的势场，每个单元格的值由场导出，幻性质源于场的对称性。文章包含交互式可视化，允许读者操作场并观察生成的幻六边形，并指出该交互在移动设备上运行良好。

hackernews · gukoff · Aug 9, 07:19 · [社区讨论](https://news.ycombinator.com/item?id=49229174)

**背景**: 幻六边形是将数字排列在中心六边形图案中，使得每个方向（三个方向）上每行数字之和相等。传统上，在数字为从 1 到单元格总数的连续整数的约束下，仅知道 1 阶和 3 阶幻六边形存在。势场方法是一种常用于物理学和机器人学的数学技术，其中标量场影响物体的行为，此处被改编用于构造幻六边形。

据报道，Windows 11 自带的天气应用占用超过 1 GB 的内存，因其过度的资源消耗而受到批评。文章指出了这一性能问题，并提到该应用的框架（包括渲染器和 GPU 进程）占据了大部分内存占用。 这个问题之所以重要，是因为它体现了现代操作系统中日益严重的臃肿问题，即简单的应用程序消耗了不成比例的系统资源。它影响了 Windows 11 用户，尤其是那些内存有限的用户，并可能影响用户对更轻量级替代方案或第三方解决方案的偏好。 文章指出，据报道，macOS 上苹果的原生天气应用占用内存不到 250 MB，形成了鲜明对比。此外，内存占用主要归因于底层框架（如渲染器和 GPU 进程），而非应用本身，并且由于共享组件的存在，准确测量内存使用情况较为复杂。

hackernews · akyuu · Aug 9, 15:11 · [社区讨论](https://news.ycombinator.com/item?id=49232138)

**背景**: Windows 11 包含多个内置应用，如天气应用，这些应用通常使用 Electron 或类似技术实现为 Web 应用。这些框架捆绑了完整的浏览器引擎，导致内存消耗高于原生应用。任务管理器可能无法清楚显示内存是否在进程间共享，从而增加了评估实际资源使用情况的复杂性。

**社区讨论**: 社区评论反映了复杂的情绪：一些人批评与 macOS 的比较，认为其同样臃肿，而另一些人则建议使用 Edge 搭配 uBlock Origin 等变通方法来减少内存占用。还有关于准确测量内存使用难度以及垃圾回收在内存膨胀中作用的技术讨论。

## [通过 SSH 和 systemd 复活四年前的 reMarkable 2](https://oskrim.github.io/hardware/2026/08/09/remarkable-over-ssh.html) ⭐️ 6.0/10

一位用户成功复活了一台因固件过时而无法正常工作的四年前 reMarkable 2 电子墨水平板，通过 SSH 访问和 systemd 服务管理手动更新并恢复其功能。这一过程凸显了该设备基于 Linux 的架构及其内置的开发者友好特性。 这很重要，因为它展示了基于 Linux 的电子墨水设备的长期可用性和可破解性，为用户提供了在官方支持之外延长硬件寿命的途径。同时，它也强调了开放、开发者友好的平台在促进社区驱动的维护和创新方面的价值。 复活过程包括通过 USB 启用 SSH，使用 systemd 控制服务，并手动修改配置文件以启用 Web 服务器。该设备出厂时已通过 USB 启用 SSH 和 root 终端访问，并内置 Web 服务器，使得无需专业工具即可进行此类修复。
