**Background**: The Navier-Stokes existence and smoothness problem, named in 2000 by the Clay Mathematics Institute as one of the seven Millennium Prize Problems, asks whether solutions to the Navier-Stokes equations always exist and are smooth in three dimensions. These equations govern fluid flow and are critical to physics and engineering. OpenAI recently claimed to have solved the problem, but the proof has not yet been formally published, and the mathematical community is still evaluating it.

## [Linux Zoom client proactively reads all X11 clipboard content](https://hachyderm.io/@simontatham/117201594980991062) ⭐️ 8.0/10

A Linux user discovered that updating the Zoom client from version 6.6 to 7.1.5 caused it to start proactively reading everything written to the X11 CLIPBOARD selection, rather than just the PRIMARY selection. This means the app now snoops on any content copied by password managers and other tools that use the standard clipboard. This is a significant privacy and security issue for a widely-used proprietary application, as it allows Zoom to potentially capture sensitive data like passwords and API keys without user awareness. It highlights ongoing concerns about trust and sandboxing for proprietary software on Linux, where the X11 protocol offers no clipboard isolation. The behavior was observed after updating from Zoom 6.6 to 7.1.5, and it specifically targets the CLIPBOARD selection (used for explicit copy/paste) rather than the PRIMARY selection (used for mouse selection). Under X11, any application can read the clipboard at any time, whereas Wayland restricts clipboard access to foreground applications.

hackernews · encyclopedism · Sep 12, 18:58 · [Discussion](https://news.ycombinator.com/item?id=49675902)

**Background**: X11 is a legacy display server protocol for Linux that does not enforce any security boundaries between applications, meaning any program can read or write the clipboard freely. Wayland, its modern replacement, restricts clipboard access to foreground applications to prevent such snooping. Zoom is a proprietary video conferencing client that has previously been criticized for security and privacy issues, including a 2019 vulnerability that allowed root access on macOS.
