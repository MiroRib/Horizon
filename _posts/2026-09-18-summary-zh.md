## [光子发射引导激光故障注入攻破 RP2350 安全调试](https://donjon.ledger.com/blog/rp2350-secure-debug-laser-fault-injection/) ⭐️ 8.0/10

Ledger Donjon 的研究人员展示了一种光子发射引导的激光故障注入攻击，能够绕过 RP2350 微控制器的安全调试保护，从而未授权访问其安全飞地。该攻击需要物理接触、破坏性芯片制备以及约 25 万美元的实验室设备。 这一攻击表明，即使是 RP2350 这样现代的安全飞地也可能被物理攻破，这对于依赖它进行硬件密钥存储等安全敏感应用的开发者至关重要。它凸显了硬件安全设计者与攻击者之间持续的军备竞赛，并可能影响未来安全芯片的设计。 该攻击利用光子发射分析定位安全逻辑，然后用激光精确瞄准以诱发故障，从而绕过调试访问控制。高成本和破坏性制备需求限制了其实用性，但正如社区讨论所示，该技术可以用更便宜的设备复现。

hackernews · synack · Sep 18, 16:54 · [社区讨论](https://news.ycombinator.com/item?id=49757050)

**背景**: RP2350 是 Raspberry Pi 推出的微控制器，具有用于可信执行和安全调试的安全飞地。故障注入攻击通过故意在芯片操作中引入错误来绕过安全措施，而激光故障注入是一种强大的物理攻击，利用聚焦光来翻转比特。光子发射分析通过观察晶体管发出的光来映射芯片活动，有助于定位攻击目标。

## [Cactus Needle 3：8-29MB 模型在工具调用上媲美 DeepSeek V4 Flash](https://cactuscompute.com/needle) ⭐️ 8.0/10

Cactus 发布了 Needle 3，这是一系列专注于自动化任务的模型，以 8-29MB 的 2-bit 二进制形式发布（2500 万至 1.21 亿参数），只处理工具调用和结构化 JSON 输出，而不做对话。其中 20 层模型在 Mobile Actions 基准上得分 86.0，超过 LFM2.5 1.2B（82.4）、Qwen3.5 0.8B（76.0）和苹果端侧模型（57.6）。 这表明极小规模的任务专用模型可以在狭窄的自动化任务上媲美大得多的 LLM，使端侧工具调用在汽车、家居和工业 PLC 等低功耗场景中变得可行。这也标志着一种趋势：生产环境中更倾向于微调小型模型，而非依赖大型通用模型。 Needle 3 采用新颖的“智能阶梯”技术，第 2 到第 20 层每一层都是可部署的子网络，共享同一套权重；同时用 Monarch Hadamard MLP 以 O(d√d) 参数量替代稠密 FFN。它支持七种语言、校准置信度分数、基于正则表达式的触发器，并覆盖从 macOS、Linux 到 iOS、Android、WebAssembly 和 RISC-V 的多种平台。

hackernews · HenryNdubuaku · Sep 18, 00:11 · [社区讨论](https://news.ycombinator.com/item?id=49748553)

**背景**: Needle 是 Cactus 推出的一系列微型模型，专门用于自动化——决定调用哪个工具并输出结构化 JSON——而非通用对话，因为在如此小的模型中塞入广泛聊天能力非常困难。“智能阶梯”意味着同一个训练好的网络可以在不同深度截断，以精度换体积；而 Monarch Hadamard MLP 是一种结构化矩阵技术，可降低前馈层的参数开销。DeepSeek V4 Flash 则是作为性能参照的更大规模前沿模型。

## [ZCode 被曝静默上传用户 Git 历史到云端](https://blog.ferstar.org/en/posts/zcode-silent-workspace-snapshot-upload/) ⭐️ 8.0/10

ferstar.org 的一篇博客披露，由 z.ai（原智谱 AI）推出、基于 GLM-5.2 的 AI 编程助手 ZCode 借“代码库索引”功能之名，静默将用户的完整 Git 历史上传至云端。其中 .git 目录单独就占上传数据量的 86.6%，z.ai 在社区讨论后发布了官方道歉声明。 该事件凸显了 AI 编程代理的严重隐私风险：上传完整 Git 历史会暴露用户以为早已删除的 API 密钥、凭证和敏感配置，影响所有将专有代码托付给这类工具的开发者与企业。这也加剧了关于沙箱隔离、权限模型以及对拥有广泛文件系统访问权的 AI 代理信任度的争论。 .git 目录占上传数据量的 86.6%，意味着云端获得了自首次提交以来的完整仓库历史，包括后续提交中已删除的历史密钥。上传行为源自 ZCode 的“代码库索引”功能，z.ai 在官方声明中致歉并将问题归因于该功能。

hackernews · csmantle · Sep 18, 06:11 · [社区讨论](https://news.ycombinator.com/item?id=49750694)

**背景**: ZCode 是 z.ai（原智谱 AI）于 2026 年中推出的免费桌面代理式 IDE，基于 GLM-5.2 模型，对标 Cursor、Claude Code 和 GitHub Copilot。AI 编程代理通常会索引代码库以提供更好的上下文，但索引范围及上传云端的内容往往不透明。Git 历史尤其敏感，因为在后续提交中删除的密钥仍可在早期提交中恢复，GitHub 官方文档也将其列为仓库清理的已知风险。

最新一期《Edge》杂志的报道汇集了多位业界老兵的评论，他们曾参与《羞辱》（Dishonored）、《网络创世纪》（Ultima Online）和《她的故事》（Her Story）等作品的开发。他们认为，游戏行业当前的危机与更深层的社会问题密切相关。正如 PC Gamer 所总结的，他们的结论是：要修复游戏行业中的问题，最终可能必须先修复现实本身。 这一评论将行业的裁员、工作室关闭和创意停滞重新定义为系统性社会问题的症状，而非孤立的商业失败，这可能会改变开发者、发行商和玩家对解决方案的思考方式。如果问题根植于现实之中，那么仅靠改善管理或采用新商业模式等行业内部手段可能远远不够。 该讨论是对《Edge》报道的摘要，而非原创报道，汇集了来自多家知名工作室和游戏系列的老兵的视角，不过 PC Gamer 的文章并未提供太多具体数据或行动方案。其核心论点带有哲学色彩：游戏行业无法脱离其所处的更广泛经济和社会背景而独自痊愈。

**背景**: 自 2023 年以来，游戏行业经历了长期的裁员、工作室关闭和整合潮，通常被归因于疫情后的过度扩张、开发成本上升以及玩家支出结构的变化。《Edge》是一本历史悠久的英国游戏杂志，以深度访谈和行业分析著称。文中提到的老兵曾参与具有影响力的作品，涵盖沉浸式模拟、早期 MMO 和叙事驱动的独立游戏，因此他们的评论更具分量。
